# 道具表

資料取自 `MAIN.EXE` 的道具表（`0x436c0` 起，每筆 25 bytes：名稱 14 bytes，其後是數值）。
欄位對應是從數值規律推出來的，標「推測」的未在遊戲畫面上逐一核對。

| 位移 | 內容 |
|---|---|
| `+15` | u16 價格（買賣基準價） |
| `+17` | 武器：攻擊力；防具：防禦力 |
| `+19`、`+20` | 附加能力的數值與種類（防具一律是種類 6，推測為術防禦） |
| `+21` | 使用（試用道具）時施放的術，編號對應術法表；`ff` 為無 |
| `+23` | 低 4 bits 是分類；原料的高 4 bits 是材質（0 金、1 銀、2 銅、3 鐵、8 翡翠、9 瑪瑙、a 水晶、b 真珠） |

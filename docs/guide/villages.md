## 遊戲的經營判斷

「村之方針」畫面依地形給出主力產業的建議：

| 地形 | 建議 |
|---|---|
| 廣闊平原 | 推動稻作 |
| 廣闊的海 | 以捕魚為中心 |
| 多山 | 以狩獵與採集為中心，逐步開墾；也可做資源調查 |
| 山地與平地平均 | 以稻作為中心，廣泛而穩定地供應糧食 |
| 土地狹小 | 提高文化與職業技術力，提升糧食生產效率 |

對各職業的評價：

- **稻作**：理想狀態，可再推動灌溉、治水等技術。
- **採集**：效率不好，應在其他職業上用心。
- **狩獵**：收穫不穩定，應逐步轉往穩定的職業；獵人太多會濫捕，造成土地價值大幅下降。
- **漁業**：較穩定。

經營的優先順序：

1. 糧食不足時，增加糧食生產人口或提升技術力，否則人口會減少。
2. 糧食生產人口太多會被判為「居民被迫過度勞動」，要維持人口比率。
3. 糧食有餘裕後，提升文化（鍛冶、玉造等文化性職業）並充實軍備。
4. 生產充足但耕地快不夠時，開墾新的耕地。
5. 目標是人口超過 3,000 人；全破條件是 30 村平均約 3,000 人以上。
6. 人口一直不增加的村：先查食料供給，再逐一檢查技術力、文化是否過低（穴門村民）。

## 劇情進度的條件

- **渡往西州**：要先把本州所有村落統合，之後向穴門海岸入口的兵士搭話，才會送你到筑紫。
  穴門村長也建議先把本州食料不穩、人口稀少的村改善好再過去。
- **削弱須佐之男**：據說所有村落生活安定、人口增加、天下太平時，須佐之男之力會減弱；
  不只要受讓村落，也要把村子經營富足（須佐、穴門村民）。

# 大地圖與村莊相鄰關係

地圖圖片是遊戲素材，不放進版控，要用下面的指令自行產生：

```sh
.venv/bin/python tools/worldmap.py build/maps --adjacency
```

會在 `build/maps/` 產生：

| 檔案 | 內容 |
|---|---|
| `world.png` | 原始大地圖（2,880×1,920） |
| `world_ja.png` | 標示日文村名 |
| `world_zh.png` | 標示中文村名 |
| `territory_zh.png` | 各村領地上色，白線是實際可走的路線（見下方「可走的路線」），菱形是迷宮；白色虛線是事件解決後就無法前往的迷宮，青色虛線是在村內對話搭船前往的島 |

格式依據見 `docs/formats.md` 的「大地圖」一節。

## 對照現代日本

```sh
.venv/bin/python tools/japanmap.py build/maps/japan_zh.png
```

把 30 個村標在它們在現代日本的對應地點（神社、古都或同名地點，皆為概略），
加 `--routes` 另出 `japan_zh_routes.png`，以灰線連起可走的路線（只畫村與村之間）。
點的顏色是遊戲進程的分組：初期南方村落（出雲、多藝志、須賀、稻羽、但馬、吉備，路線多為單線或簡單分支）、
中期 1（勢力地圖東南方的三輪、熊野、阿波見、伊吹、尾張、美濃、山城，開始有軍隊戰鬥、路線可自由選擇）、
中期 2（勢力地圖北方與東北方的燒津、相模、新治、科野、越、和奈美、相樂、沼河、須佐、穴門）、
後期左上村落（筑紫、阿多、日向、隼人、宇佐、伊都、熊曾）。圖上另標出瀨戶內海的位置。
和奈美（ワナミ）出自古事記「和那美之水門」：垂仁天皇之子本牟智和氣說不出話，山邊之大鶙追一隻天鵝
（鵠）一路經過多國，最後在高志國（越）的和那美之水門張網捕到。國學院大學的古事記地名資料庫記為
「伝承地未詳」；有人主張是新潟縣長岡市川口的「和南津」（魚野川畔，地名音近），圖上暫放在那裡並標「？」。
遊戲裡和奈美與越、科野、相樂相鄰，也與越後一帶的位置相合。日本的輪廓需要先下載，指令在 `tools/japanmap.py` 的說明裡。

遊戲的範圍大約是**九州到關東、北陸**：西起九州南端（阿多、隼人），東到常陸（新治，茨城）與
相模（神奈川），北到越後一帶（沼河，新潟糸魚川）。四國、東北、北海道沒有出現。
但遊戲的大地圖**不是照地理比例畫的**：把村莊大門的位置與這些地點做仿射對位，平均仍差約 650 像素
（地圖寬 2880），例如九州在遊戲裡位於左上、出雲一帶在左下，相樂、穴門在上方。所以沒有把
`world.png` 變形疊上去，只用顏色對照。

## 勢力地圖

村莊畫面右側那張區塊地圖：

```sh
.venv/bin/python tools/forcemap.py build/maps
```

產生 `force.png`（只上色、不標字）、`force_ja.png`、`force_zh.png`：30 個區塊上色並標上村名，放大 4 倍。
相鄰的區塊不會同色；遊戲裡區塊的顏色依勢力變化，這裡的顏色只是為了區分各村。
村名用點陣字體 DotGothic16（SIL OFL）。第一次使用前要先下載到 `build/fonts/`，指令在
`tools/forcemap.py` 的說明裡。

## 村莊平面圖

```sh
.venv/bin/python tools/villagemap.py build/maps/villages
```

輸出到 `build/maps/villages/`：

- `NN_村名.png`：原始平面圖。
- `NN_村名_label.png`：標出村長家、倉庫、鍛冶屋、渡口和入口。「民家？」「商人？」
  是還沒確認的建築種類（見 `facilities.md`）。
- `all.png`：32 張平面圖的總覽。

編號 0–28 依村序，29 是熊曾，30、31 是霧中大陸的邪馬與血沼（血沼村中有座高大的神殿）。
船之類由事件出現的物件沒有畫進去。

不一定等於遊戲中的樓層。

## 地圖上的其他地點

- 洞窟入口共 9 處（metatile 4，座標以 32 像素的格計）：

  | 格 | 位置 | 對應 |
  |---|---|---|
  | (27,26) | 日向領地內 | 高千穗岳 |
  | (22,41) | 出雲東方 | 黄泉比良坂（出雲可前往；離出雲最近的入口） |
  | (75,52) | 三輪領地內 | 三輪山 |
  | (59,8) | 沼河領地內 | 生贄洞窟 |
  | (50,9) | 須佐領地內 | 須佐沼 |
  | (51,56) | 吉備南方外海的小島 | 鬼之島（吉備村：「此村外海之島上，棲息著鬼」） |
  | (80,6) | 地圖右上角、和奈美外海的島 | 海賊之島（和奈美村：「那些廝的巣穴是此村外海的小島」） |
  | (60,44) | 伊吹領地內 | 伊吹山（由伊吹前往，玩家確認） |
  | (44,46) | 稻羽領地內 | 山賊洞窟（由稻羽前往，玩家確認） |

- 地圖左上角那塊淺色地是霧中大陸（邪馬、血沼），從熊曾外海前往（「便會出現在熊曾村外海」）。
- **中央的大片水域**：四周依序是西州（筑紫、阿多、日向）、上方的穴門與須佐、右邊的燒津與尾張、
  下方的稻羽一帶。劇情裡的龍宮城（海道）由尾張、燒津出海前往。位置上像是把**瀨戶內海**
  （九州、中國、近畿之間的內海）放大後擺在中央，但遊戲沒有替它命名，周圍的村也不照實際地理排列，
  所以只能說「功能上像瀨戶內海」，不是精確對應。
- **小島**：
  - 右上角和奈美外海的島是海賊之島。若和奈美照古事記在越後（見上），對應的現實島嶼最接近**佐渡島**。
  - 吉備南方外海的小島是鬼之島，對應桃太郎傳說的鬼ヶ島（一說是瀨戶內海的女木島）。
  - 中央水域裡的島、隼人西方的幾個小島，沒有村莊、洞窟或劇情提及，看不出對應；若硬要比附，
    前者位置像淡路島，後者像薩摩外海的甑島、種子島，但都沒有遊戲內的根據。

# 大地圖與村莊相鄰關係

地圖圖片是遊戲素材，不放進版控，要用下面的指令自行產生：

```sh
.venv/bin/python tools/worldmap.py build/maps --adjacency
```

會在 `build/maps/` 產生：

| 檔案 | 內容 |
|---|---|
| `world.png` | 原始大地圖（2,880×1,920） |
| `world_ja.png` | 標示日文村名 |
| `world_zh.png` | 標示中文村名 |
| `territory_zh.png` | 各村領地上色，白線連接相鄰的村 |

格式依據見 `docs/formats.md` 的「大地圖」一節。

## 勢力地圖

村莊畫面右側那張區塊地圖：

```sh
.venv/bin/python tools/forcemap.py build/maps
```

產生 `force_ja.png`、`force_zh.png`：30 個區塊上色並標上村名，放大 4 倍。
相鄰的區塊不會同色；遊戲裡區塊的顏色依勢力變化，這裡的顏色只是為了區分各村。
村名用點陣字體 DotGothic16（SIL OFL）。第一次使用前要先下載到 `build/fonts/`，指令在
`tools/forcemap.py` 的說明裡。

## 村莊平面圖

```sh
.venv/bin/python tools/villagemap.py build/maps/villages
```

輸出到 `build/maps/villages/`：

- `NN_村名.png`：原始平面圖。
- `NN_村名_label.png`：標出村長家、倉庫、鍛冶屋、渡口和入口。「民家？」「商人？」
  是還沒確認的建築種類（見 `facilities.md`）。
- `all.png`：32 張平面圖的總覽。

編號 0–28 依村序，29 是熊曾，30、31 是霧中大陸的邪馬與血沼（血沼村中有座高大的神殿）。
船之類由事件出現的物件沒有畫進去。

## 迷宮地圖

```sh
.venv/bin/python tools/dungeonmap.py build/maps/dungeons
```

輸出 `NN_名稱-F.png`（第 F 層）與 `NN_名稱.png`（整座迷宮各層並排），共 13 座、85 層：

| 40 | 天之真奈井 | 1 | |
| 41 | 黄泉比良坂 | 7 | 遊戲開場 |
| 42 | 山賊洞窟 | 6 | |
| 43 | 鬼之島 | 9 | |
| 44 | 三輪山 | 10 | 森林 |
| 45 | 伊吹山 | 6 | 森林 |
| 46 | 海道 | 3 | 宮殿樣式 |
| 47 | 海賊之島 | 3 | |
| 48 | 生贄洞窟 | 4 | |
| 49 | 須佐沼 | 4 | 森林 |
| 50 | 高千穗岳 | 10 | 森林，在日向旁邊 |
| 51 | 死靈祭壇 | 9 | |
| 52 | 邪馬神殿 | 9 | 第 6 層是頭目房（龍之石像祭壇），不遇敵 |

名稱取自 `MAIN.EXE 0x519ce` 起依序排列的 13 個迷宮名，順序與 entries 40–52 一致。
可以佐證的有三點：開場洞窟（41）是黄泉比良坂；須佐頭目戰前的快照在 49 號；
高千穗岳在日向旁、以森林為主（玩家確認）。大地圖上 9 個洞窟入口目前只對上高千穗岳
（日向旁的 (27,26)）。樓梯、寶箱位置還沒解出來；層的編號是資料裡的順序，
不一定等於遊戲中的樓層。

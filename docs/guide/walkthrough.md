# 序盤流程與系統要點

開頭到熊野的流程，以及戰鬥、戰爭、村落經營的系統細節。內容整理自日文部落格「埼玉帝国」的三回遊玩紀錄
（PC-9801 版，見文末參考來源）。名稱已換成中文版的譯名；標「部落客推測」的是原作者自己也不確定的說法。

## 目標

統合葦原中國全部村落，並讓各村人口達到約 3,000 人以上（見 [`villages.md`](villages.md) 的經營參考）。
人們求平和則天照之力增強，求戰亂則須佐之男之力增強。所以要破關，劇情（RPG）和村落經營（SLG）兩邊都得推進。

## 序盤流程

| 地點 | 取得方式 |
|---|---|
| 黃泉比良坂 | 天照命你先去取武器。途中須勢理姫被須佐之男附身，醒來後加入。打倒**漆黑大蛇**得生太刀，打倒**血潮蜈蚣**得生弓矢，帶回大廣間後須佐之男現身誘惑，天照之聲喚醒主角。 |
| 出雲 | 村長建比良鳥進洞窟查探須佐之男後性情大變。進入村長家後開戰，建御名方負責周圍兵士，你專心打建比良鳥。打倒後他恢復神智隨即死去，建御名方讓出出雲並加入隊伍。 |
| 多藝志 | 與出雲是兄弟村，聽說出雲已讓出，**無條件**讓出。 |
| 須賀 | 稻作技術不足，秋收再不好村長就會被趕走。向多藝志的人取得封有**少名毘古那**的道具，帶到須賀使用，稻子就長起來了。 |
| 稻羽 | 山賊頭目手力是村長之子，村長不肯見人。進山賊洞窟打倒手力，他改過自新後，村長讓出稻羽。 |
| 吉備 | 村長吉備津彥夜裡駕船出海。和村人建耳杉一起跟蹤到鬼之島，發現村長已被殺，是**牛鬼**假扮的。鬼之島有十拳劍（須勢理姫無法裝備）。 |
| 三輪 | 闖過大物主在三輪山設下的試煉。山中迴圈多，按開關會打開樹洞傳送，場景相似容易迷路。通過後大物主以人形加入，身分是「天神」，非常強。 |
| 熊野 | 村長是天照派，故意要你「用武力奪取」，當作戰爭的教學。敵方大將是高倉下。 |

熊野之後，有些村只能靠戰爭取得。

## 頭目弱點

大型敵人身上有弱點部位，敵人會頻繁轉向，不容易穩定打到。

- **漆黑大蛇**：部落客推測是尾巴。第一次全滅，重來時先替須勢理姫換上撿到的裝備，讓她專心防禦和回復，由主角主攻，就打贏了。
- **血潮蜈蚣**：部落客推測是尾部。
- **牛鬼**：弱點在尾部，村人的對話也有提示。派一人在頭部那側當誘餌並防禦，其他人從後面攻擊。
- **手力**：會用回復術，回復量大。先集中打倒周圍的雜兵（體力低）再圍攻他，比較快。

## 戰鬥系統

- 戰場是六角格，敵我都有**面向**。從背後攻擊效果好，也容易出會心一擊；敵人從背後打你也一樣。
- **行動力制**：每回合累積行動力。移動、攻擊、防禦都很耗行動力，通常一回合只能做其中一項。但如果不用移動就打得到，可以攻擊後再防禦，或先施術再攻擊（同一種行動不能重複）。所以每個角色行動完都要**自己按「終了」**，回合才會結束。
- 指令依隊伍順序輸入，正在輸入指令的角色會閃爍。若被「命令表」視窗擋住，看不出輪到誰時，可以從輸入順序推算。
- 氣力（術用）消耗相對最大值偏高，很快就會用完，要常回村補給。部落客查到：開發時原本是「升級時體力、氣力全滿」，後來拿掉了，但術的消耗沒有跟著調整。
- 弓矢可以遠距攻擊，但敵人防禦高，傷害很低，實戰不太好用。
- 迷宮大多有迴圈，不是單純的樹狀結構，靠「沿右手（左手）牆走」的方法走不完。地圖見 [`dungeons.md`](dungeons.md)。

## 戰爭

- 戰前先在各村**徵兵**為預備兵，讓武人類人物指導（調練），再編入隊伍成員旗下，每人約可帶 2 部隊。
- 從各村徵到的幾乎都是弓矢兵，輕裝兵很少（部落客推測與鍛冶技術有關）。三輪有很多騎馬兵，可能是因為馬部多。騎馬兵機動力高，很好用。
- 下達攻擊指令後不會馬上開打，要等所有部隊移動完才交戰；攻擊同一部隊的友軍會一起參戰。
- 全滅有敵將在的部隊就能**俘虜**他。俘虜敵方大將時戰爭立即結束，即使場上還有其他部隊。
- 大將在戰後**自動處死**，無法選擇；其他被俘人物則歸順我方。

## 村落經營

- **移動**：大地圖只能移動到**相鄰**的村（路線見 [`map.md`](map.md)），進村後還要走到村長家才能下指令，所以巡視全國很花時間。
- **委任**：沒有委任的村，主角不在時什麼都不會做，取得村落後一定要委任。初期各村存糧都很危險，建議方針選「食料生產」，委任的人物挑符合該村主要糧食來源的身分（例如農民）。
- **村之現狀**：先看右側的食料關係，包括主要糧食來源、供需與存糧狀態。開局各村普遍缺糧，第一次秋收後就會恢復正常。
- **食料供給率**：開局 100%，逐步調高。調高後能把更多人力移到食料以外的工作（部落客的理解，不確定）。
- **傳播文化**：花 1 節提升文化度和各項技術。連續使用會出現「居民不願聽從」，隔一段時間才能再提升。
- **人物**：可以指導對應身分的職業，提升熟練度（武人只能指導兵士、狩獵等）；也能派去探勘資源、開墾土地，或委任經營。下達「中止命令」讓人物空閒後，就能找他加入隊伍。
- 新年時人口會增加。存糧到「有餘裕」後，再把糧食人力逐步轉到鍛冶、玉造、土師等文化性職業，或徵兵。

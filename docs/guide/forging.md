# 鍛冶與武器打造

整理自遊戲內村民的對話（劇情 block 0、3、4、7、9、19、20、26、45）與道具表的數值。

## 基本規則

- 帶**鐵鑛、銅鑛等原料**到有**鍛冶屋**的村子，就能請他們打造武器或防具；沒有原料就打造不了。
- 成品好壞取決於該村的**鍛冶技術**（職業熟練度）：技術不高的村做不出好東西。
- 村子的鍛冶、玉造在日常生產中**偶爾會做出好東西**，收進寶物庫。
- 稀有原料只有技術力高的村處理得了。
- 村子的鍛冶部除了武器，也能生產道具；但馬村民認為與其造武器，造有用的道具更要緊。

村子的「鍛冶生産内容」可在下列項目中指定：鐵武器、銅武器、鐵農具、銅農具、銅鐸、鐵鏡、銅鏡。
沒有鍛冶與玉造的居民時，這些指令無法執行。

## 各村的鍛冶屋情報

| 村 | 情報 |
|---|---|
| 出雲 | 村裡有鍛冶屋，取得鐵鑛或銅鑛後可打造武器防具 |
| 但馬 | 四面環山，鍛冶材料豐富，技術以高超聞名（稻羽村民也這麼說）；人數與技術再提升能做出更多東西 |
| 三輪 | 玉造與鍛冶興盛；帶鐵鑛去會打造**特殊的槍**（熊野村民說） |
| 伊吹 | 礦石中可能出現極罕見的**天津金**，打造的武器防具極為精良，但只有技術力高的村能處理 |
| 越 | 鍛冶屋傳有打造**討伐大蛇之劍**的秘傳，帶鐵鑛去就肯打造（用來對付沼河出現的怪物） |
| 沼河 | 玉造興盛；鍛冶屋會打造**綴有玉飾的鎧甲**（玉飾鎧），翡翠等石頭之力能提高防禦 |
| 隼人 | 鍛冶屋能用鐵打造**弓矢**（鐵弓），威力大但不好駕馭，失手會變多 |
| 山城 | 有鍛冶屋等各式店家，適合整備裝備 |

## 原料

| 原料 | 基準價 | 用途 |
|---|--:|---|
| 銅鑛 | 100 | 銅武器、銅農具、銅鐸、銅鏡 |
| 鐵鑛 | 320 | 鐵武器、鐵農具、鐵鏡；三輪的槍、越的大蛇之劍、隼人的鐵弓 |
| 黒鐵 | 600 | 鐵系原料（推測可打造黒鐵太刀、黒鐵胴） |
| 天津金 | 1200 | 鐵系的最高級原料，需高技術力 |
| 金塊／銀塊 | 800／720 | 貴金屬 |
| 翡翠／瑪瑙／水晶原石 | 240／160／120 | 玉造的材料（勾玉、指環等） |

原料可經由村的「資源調査」發現（多山的村，遊戲會建議做資源調查）。
價格與分類見 [`items.md`](items.md)。

# 迷宮的寶箱、樓梯、門與機關

由 `.venv/bin/python tools/dungeonmap.py --list` 從 `VDMAP.DAT` 產生，欄位意義見
`docs/formats.md` 的「迷宮地圖」。地圖編號 MAP NN-A、B、C… 與 `build/maps/dungeons/` 的圖檔一致；
座標是 (x,y)，以格子（16×16 像素）為單位，左上角是 (0,0)，要換算成圖上位置就乘以 16。

可信度：

- **樓梯／出入口**、**門**：連接關係已驗證（樓梯與門共 196 組互相指回對方）。
- **寶箱**：位置與內容來自寶箱記錄；全遊戲共 50 個，各有一個不重複的「已開啟」編號。
  標 ＊ 的 4 個有特殊旗標，意義未明。
- **傳送陣**：只列出已確認的種類（邪馬神殿 MAP I 的發光圓圈）。
- **機關**：位置上的圖案都是開關，但按下後會打開哪扇門還沒解出來。

標記版地圖：

```sh
.venv/bin/python tools/dungeonmap.py build/maps/dungeons --guide build/maps/dungeons_guide
```

`build/maps/dungeons_guide/` 裡的圖與 `dungeons/` 同名，多了標記：黃框「寶n」是寶箱（內容列在圖下方），
綠框「→B」是樓梯／出入口（「→出口」回大地圖），藍框「門→B」是門，紫框「傳送」連線到目的地，
紅框「機關」是開關。寶箱是地圖上的物件而不是 tile，所以圖上只看得到框、看不到箱子；
樓梯的記錄位置是踩上去會觸發的那一格，常在樓梯圖案的上方一格。

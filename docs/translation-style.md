# 翻譯風格指南

持續更新。翻譯時遇到的取捨、專有名詞表記、以及字庫缺口的處理原則都記在這裡。

## 語域

整體定在**偏文言、帶古日語翻譯腔**，不艱澀。題材是古事記神話，這個調性比
現代白話更合。

| 角色 | 自稱 | 對主角的稱呼 |
|---|---|---|
| 神明（天照、少名毘古那） | 吾 | 汝 |
| 村長、武人 | 我／在下 | U大人、閣下、汝 |
| 一般村民 | 我 | U大人、大哥哥 |
| 山賊、粗人 | 老子／我 | 汝、這廝 |

這不只是風格選擇，也是被字庫逼出來的：`你` `您` 都不在 JIS X 0208 內，
第二人稱只剩 `汝` `君` `爾`，白話根本寫不成。詳見下節。

## 字庫缺口的處理原則

JIS X 0208 是日文字集。拿 192 個中文最常用字測只缺 7 個（3%），
但缺口分布**極不平均**：文言／書面語幾乎無礙，**口語是重災區**。

`tools/jis.py` 會列出缺字並給建議，`tools/event.py verify` 會整批擋下。

### 疑問句

`嗎` 不存在。依句長與語氣分三種處理：

| 情境 | 寫法 | 例 |
|---|---|---|
| 短問句 | 「可否？」 | 可以嗎？→ 可否？ |
| 長問句 | 句尾用「乎？」 | 這是真的嗎？→ 此事當真乎？ |
| 反問、詰問 | 句尾用「邪？」 | 汝也要與我為敵邪？ |

`麼` 在字庫內，語氣較輕時仍可用（「是麼」「真的麼」）。

### 語尾助詞

`啊 喔 嗎 呢 吧 哪` 全缺，只剩 `呀` `嘛`。
依語氣改用文言助詞 **`也 / 矣 / 哉 / 夫 / 耳 / 焉`**，或整句改成直述。

### 字形選用：繁體優先

這是**繁體中文化**，所以規則是：

> **JIS X 0208 有繁體字形就用繁體，只有缺字時才退回日系新字體。**

下面那張替換表是「繁體缺字」的清單，不是偏好清單。除了表內那些字，
一律寫 `讓` 不寫 `譲`、`戰` 不寫 `戦`、`選擇` 不寫 `選択`、`龍宮` 不寫 `竜宮`。

同一個字混著寫，單看一行不會錯，連起來玩就很明顯。
`tools/consistency.py` 會整批掃出兩類問題：

1. **變體混用** —— 同一個字兩種寫法都出現，列出少數派的位置
2. **同原文多種譯法** —— 同一句日文被譯成不同結果

第 2 類對**句尾續段**（`になりました`、`なければな…` 這種跨訊息的片段）
會誤報，因為它們本來就接在不同的前文之後；其餘都該修。

### 可直接替換成日系新字體的字

讀起來不影響，直接換：

```
產→産  查→査  錄→録  說→説  每→毎  內→内  姊→姉  溫→温
彥→彦  黃→黄  眾→衆  歷→歴  步→歩  淚→涙  黑→黒  增→増
絕→絶  擊→撃  鄉→郷  剝→剥  啟→啓  寬→寛  值→値  巢→巣
狀→状  綠→緑  沉→沈
```

> **`cp932` 不等於 JIS X 0208。** cp932 多收了 NEC 第 13 區與 NEC/IBM
> 擴充區約 400 字，這些字編碼得出來、但 DOS/V 字型沒有字模，畫面上是空白。
> 「黑」(0xEEEC) 就是這樣被抓到的。`tools/jis.py` 檢查的是 Shift-JIS 的
> lead byte，不是「cp932 能不能編碼」。

### UI 文字的額外約束

UI 字串是**就地覆寫**（`tools/patch.py`），與劇情的變長回寫不同，有三條硬限制：

1. **不可超過 `max_bytes`** —— 原字串到 NUL 為止的長度。超出就踩到下一筆資料。
2. **`%s` `%d` `%u` `%4d` `%-14s` `%6lu` 等格式符號必須原樣保留、順序不變**，
   個數也不能增減；引擎照順序填值。
3. **半形空白是版面對齊用的**，不是可有可無的裝飾。
   譯文字數變短時要補空白維持右對齊，例如
   `重装の鉄普及率        %3d％` → `重装鉄普及率          %3d％`（補 2 格）。

另外 `extracted/text/main_ui.tsv` 裡有約 90 筆的 offset 落在字串中段，
抽出來會帶一截亂碼前綴（如 `窰轜職業選択`、`痳村の方針`）。
這些要先往回找到前一個 NUL 之後的真實起點，再跳過前綴資料位元組，
只覆寫純日文那一段 —— 亂碼前綴是前一筆資料的尾巴，覆寫掉會壞檔。

## 用語統一

同一個概念在不同畫面重複出現時，用字必須一致，否則玩家會以為是兩件事：

| 日文 | 統一譯法 | 不要用 |
|---|---|---|
| 〜しますか？ | 〜乎？ | 〜嗎？（缺字） |
| よろしいですか？ | 可否？ | 確定嗎？ |
| 選択してください | 請選擇 | 請選択（`擇` 在字庫內，用繁體） |
| 外に出る | 往外而出 | 離開／出去 |
| すばやさ | 敏捷度 | 速度／敏捷 |
| 器用さ | 器用度 | 靈巧 |
| 仲間 | 同伴 | 夥伴（`夥` 缺） |
| ディスク | 磁片 | 磁碟 |
| 宝物一覧 | 寶物一覽 | 寶物一覧 |
| ドライブ | 磁片機 | 磁碟機／驅動器 |
| 道具 | 道具 | 物品（`所持品` 才譯物品） |
| データ | 資料 | 數據 |
| エラー | 錯誤 | 異常 |
| 最初からゲームをする | 開始新遊戲 | 從頭開始 |
| 途中からゲームをする | 繼續遊戲 | 從中途繼續 |

## 格式限制

- **每則訊息上限 70 bytes**（全形字 2 bytes、控制碼 1 byte）。
- **控制碼必須原樣保留**，連順序都不能變。`tools/event.py verify` 會比對
  原文與譯文的 ASCII 序列，不符就擋下。

| 碼 | 作用 |
|---|---|
| `G` | 換行 |
| `W` | 等待輸入 |
| `N` / `X` | 接在 `G` 後，換頁／清窗 |
| `S` | 敘述模式（出現在訊息開頭） |
| `U` | 主角名變數 |
| `Y` | 是／否選項 |
| `Cnnn` | 接續到本 block 的第 nnn 則 |
| `Fnnn` | 另一種跳轉，語意未驗證 |
| `%s` | printf 格式符（UI 字串） |

訊息常在句子中間被切成數段再用 `Cnnn` 串接。中文斷句與日文不同，
**可以重新分配各段的內容**，只要每段不超過 70 bytes、控制碼序列不變即可。
